# Changelog

## 0.1.1

- Fix characters typed in the Symbol font (such as ←, ∧, γ) showing as empty boxes.

## 0.1.0

- Initial release: view `.pptx` files in an editor tab with continuous scrolling,
  thumbnails, search, zoom, pinch-to-zoom and speaker notes.
- Reloads automatically when the file changes, including apps that save by replacing the file.
